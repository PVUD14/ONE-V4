The ONE logo in the app: preview for approval

ONE is the application and AI8HT is the organisation. Every brand slot in the web app, the pilot and the Android app now shows the ONE logo. AI8HT stays wherever the organisation is meant: "by AI8HT", the copyright and trademark lines, and "AI8HT operations". Everything below is taken from the feat/one-brand branch. The screenshots are real renders: headless Chrome for the web and the Android emulator (API 36) for the app. The last row uses mock-ups where a live render needs a signed-in session.
