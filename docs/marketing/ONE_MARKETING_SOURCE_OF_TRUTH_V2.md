# ONE Marketing Source of Truth V2

## Available today

- Real Cognito-backed ONE login for UAT identities.
- Authenticated Student, Institution, Employer and Operations routing.
- Student-owned profile preference persistence.
- Student document metadata management.
- Student saved opportunity references.
- Institution organization/unit/student/roster/staff invitation APIs.
- Operations organization lifecycle, verification and initial-admin invitation APIs.
- Career Readiness read surfaces and operational status.

## Partial

- Student dashboard uses real identity and selected real persistence; some readiness panels remain limited to existing backend coverage.
- Institution and Operations authenticated portals have real APIs, but not every richer dashboard control has a dedicated polished operating UI yet.
- Content Operations is read/status-oriented; authoring is not available.

## Not yet available

- Secure binary document storage/upload.
- Employer hiring workflow: opportunities, applications, interviews, offers.
- Full Placement workflow.
- Full Faculty/Department workflow.
- Large content authoring CMS.
