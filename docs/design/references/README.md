# Design references

These files are the approved visual references used to reproduce the Student portal foundation direction.

- `01-role-portal-matrix.png` — role portal matrix showing the multi-portal product model, shared shell language, and role-specific surfaces.
- `02-institutional-detailed-dashboard.png` — detailed staff dashboard reference for dense enterprise cards, left navigation, status panels, and operational layout rhythm.
- `03-four-portal-visual-system.png` — four-portal visual system reference; the Student panel is the primary source for the approved Student shell, light workspace, compact topbar, sidebar, cards, and responsive direction.
