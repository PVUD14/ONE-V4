## Rule

Customer-facing UI, browser titles, invitations, emails, reports, exports, public docs, and marketing inputs must use ONE or ONE by Ai8ht. Internal package names, repository names, environment variable names, server paths, and architecture history may temporarily retain PlanThePath/planthepath-next until a later engineering rename.
